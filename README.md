# CiudadanIA

Prototipo web de Gestión de Formularios desarrollado con Python 3, SQLite y el patrón MVC. Permite al investigador gestionar portafolios, formularios y preguntas. La aplicación aplica las reglas de publicación, cierre e integridad de datos del módulo.

## Ejecutar desde VS Code

1. Abre esta carpeta en VS Code.
2. En macOS, presiona **Cmd + Shift + B**. En Windows o Linux, presiona **Ctrl + Shift + B**. También puedes elegir **Terminal → Run Build Task**.
3. Entra a [CiudadanIA](http://127.0.0.1:8000) en el navegador. Detén el servidor con **Ctrl + C** en la terminal.

Requiere Python 3. Consulta [LEEME.md](LEEME.md) para iniciar desde una terminal. SQLite crea la base local al iniciar.
